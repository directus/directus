Updated the MCP server to the 2026-07-28 protocol while still serving 2025-era clients, fixed notifications such as `notifications/cancelled` leaving the request open, made `prompts/list` return an empty list when no prompts collection is set, allowed the new MCP request headers in CORS preflights on `/mcp`, and reported the Directus version as the server version

::: notice

2025-era MCP clients now receive responses as a single server-sent event and must send `Accept: application/json, text/event-stream`, as the MCP specification requires. Clients that only accept `application/json` get a 406 and need to send both types and read the event stream. Claude, ChatGPT, VS Code, Cursor, and the official MCP SDKs already do

:::
